# เว็บไซต์วิทยาลัยเทคนิคนางรอง (สำหรับฝึกทำใน VS Code)

## ไฟล์ในโปรเจกต์
- `index.html` หน้าแรก มีปุ่ม 3 ปุ่ม
- `about.html` รายละเอียดเกี่ยวกับวิทยาลัย
- `map.html` แผนที่และปุ่มเปิด Google Maps
- `contact.html` ข้อมูลติดต่อ
- `style.css` สีสัน รูปแบบ ปุ่ม และการจัดหน้าให้รองรับมือถือ
- `images/` โฟลเดอร์สำหรับใส่รูปของคุณ

## วิธีเพิ่มรูปภาพ
นำรูปของวิทยาลัยมาใส่ในโฟลเดอร์ `images` และตั้งชื่อให้ตรงกับโค้ด:
- `campus.jpg` รูปหลักหน้าแรก
- `welcome.jpg` รูปเสริมหน้าแรก
- `college-building.jpg` รูปหน้าเกี่ยวกับวิทยาลัย
- `activity.jpg` รูปกิจกรรมในหน้าเกี่ยวกับวิทยาลัย
- `map-photo.jpg` รูปแผนที่แบบภาพนิ่งในหน้าแผนที่ (แผนที่จริงยังฝังจาก Google Maps)
- `contact-photo.jpg` รูปหน้า contact

ชื่อไฟล์ต้องตรงกันทุกตัวอักษร หากรูปเป็น PNG ให้เปลี่ยนทั้งนามสกุลในไฟล์และใน `src` เช่น `campus.png`

## วิธีเปิดเว็บ
1. เปิด VS Code
2. เลือก File > Open Folder แล้วเลือกโฟลเดอร์ `nangrong-website`
3. ติดตั้งส่วนขยาย Live Server จาก Extensions
4. คลิกขวา `index.html` แล้วเลือก Open with Live Server
5. คลิกปุ่มทั้งสามเพื่อตรวจสอบว่าลิงก์ไปยังหน้าแยกกันได้

## อธิบายโค้ด HTML
- `<!DOCTYPE html>` บอกเบราว์เซอร์ว่าเอกสารนี้ใช้ HTML5
- `<html lang="th">` เริ่มเอกสาร HTML และบอกว่าภาษาหลักเป็นภาษาไทย
- `<head>` เก็บข้อมูลตั้งค่าหน้า ไม่ใช่เนื้อหาหลักที่แสดงในเว็บ
- `<meta charset="UTF-8">` ช่วยให้ภาษาไทยแสดงผลถูกต้อง
- `<meta name="viewport"...>` ทำให้ขนาดหน้าเหมาะกับมือถือ
- `<title>` ตั้งชื่อแท็บเบราว์เซอร์
- `<link rel="stylesheet" href="style.css">` เชื่อมไฟล์ CSS
- `<body>` คือส่วนที่แสดงบนหน้าเว็บ
- `<header>` เป็นส่วนหัว เช่น โลโก้และเมนู
- `<nav>` รวมลิงก์นำทาง
- `<a href="about.html">...</a>` สร้างลิงก์ไปหน้า about.html; เปลี่ยน href เป็นชื่อหน้าอื่นเพื่อเปลี่ยนปลายทาง
- `<main>` ครอบเนื้อหาหลักของหน้านั้น
- `<section>` แบ่งเนื้อหาเป็นส่วน ๆ
- `<div class="...">` เป็นกล่องจัดกลุ่มองค์ประกอบ โดย class ใช้เลือกตกแต่งใน CSS
- `<h1>`, `<h2>`, `<h3>` เป็นหัวข้อระดับต่าง ๆ
- `<p>` เป็นย่อหน้าข้อความ
- `<ul>` คือรายการแบบจุด และ `<li>` คือแต่ละรายการ
- `<img src="images/campus.jpg" alt="...">` แสดงรูป: `src` คือที่อยู่ไฟล์รูป ส่วน `alt` คือข้อความอธิบายรูป
- `<iframe>` ฝังเนื้อหาจากเว็บไซต์อื่น ในโปรเจกต์นี้ใช้แสดง Google Maps
- `<footer>` คือส่วนท้ายเว็บไซต์
- `</ชื่อแท็ก>` ใช้ปิดแท็กส่วนใหญ่ เพื่อบอกว่าเนื้อหาส่วนนั้นจบแล้ว
- `<!-- คำอธิบาย -->` คือคอมเมนต์สำหรับคนเขียนโค้ด ไม่แสดงบนหน้าเว็บ

## อธิบาย CSS
- `selector { ... }` เลือกองค์ประกอบที่ต้องการตกแต่ง
- `*` เลือกองค์ประกอบทุกตัว
- `body` ตั้งค่าทั่วไปของหน้าเว็บ
- `.` นำหน้าชื่อ class เช่น `.navbar` หมายถึงองค์ประกอบที่มี `class="navbar"`
- `margin` คือระยะห่างด้านนอก
- `padding` คือระยะห่างด้านใน
- `color` คือสีตัวอักษร
- `background` คือพื้นหลัง
- `font-family` คือแบบอักษร
- `font-size` คือขนาดตัวอักษร
- `display: flex` ช่วยจัดองค์ประกอบในแนวแถว/คอลัมน์
- `justify-content` จัดตำแหน่งตามแนวหลัก
- `align-items` จัดตำแหน่งตามแนวขวาง
- `gap` คือช่องว่างระหว่างองค์ประกอบ
- `border-radius` ทำมุมโค้ง
- `box-shadow` สร้างเงา
- `width: 100%` ให้กว้างเต็มพื้นที่ที่มี
- `max-width` / `max-height` กำหนดขนาดสูงสุด
- `object-fit: cover` ครอบรูปให้เต็มกรอบโดยไม่ทำให้รูปยืดผิดสัดส่วน
- `:hover` คือรูปแบบเมื่อเอาเมาส์ชี้
- `@media (max-width: 650px)` คือกฎสำหรับจอขนาดเล็ก เช่น โทรศัพท์
- `linear-gradient(...)` สร้างพื้นหลังไล่สี

## ก่อนเผยแพร่จริง
ตรวจสอบประวัติ ที่อยู่ เบอร์โทรศัพท์ และข้อมูลทั้งหมดกับแหล่งทางการของวิทยาลัยก่อน เพราะข้อความตัวอย่างอาจต้องแก้ไขให้เป็นข้อมูลล่าสุด
